About the project

What is bone age?

Bones change shape and density as a child grows. Doctors compare a hand X-ray with reference standards to find the "bone age", which shows how mature the skeleton is. This project predicts it automatically from the X-ray image.

Questions

Do I need to enter the age?

No. The age is predicted from the X-ray, so you only upload the image.

Is the result a medical diagnosis?

No. This is an academic project and results are for demonstration only.

Where is my history stored?

Only in your own browser on this device. Nothing is uploaded anywhere.
